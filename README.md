# 汤力策略精选 · 基金策略跟踪器

**TANGLI FUND DISCIPLINE · Designed by 汤力**

一套自部署的基金策略记录工具：组合页用于汇总，单标的页面独立计算回撤、买入档位与持仓记录。数据来自天天基金公开 API。

## 使用方式

**Web 界面（推荐）**：启动服务后，浏览器打开 `http://localhost:8080`。

**命令行**：

```bash
pip install -r requirements.txt
```

## 策略说明

当前版本采用单标的独立资金上限和每档一次的阶梯信号。组合首页只负责汇总展示，不参与任何标的的买卖判断。完整原理、利差定投和回测判定请阅读 [STRATEGY_V2.md](STRATEGY_V2.md)。策略参数是可检验的规则假设，不宣称已经得到未来有效的最优参数。

### 买入规则（阶梯式加仓）

**低波红利**（008163, 008114, 159307）：入场 3%，每 2% 一档，乘数 ×1.3

| 回撤范围 | 档位 | 买入金额（¥10,000 × 3%） |
|----------|------|--------------------------|
| < 3% | — | 不操作 |
| 3%–5% | 第1档 ×1.00 | ¥300（只执行一次） |
| 5%–7% | 第2档 ×1.30 | ¥390（只执行一次） |
| 7%–9% | 第3档 ×1.69 | ¥507（只执行一次） |
| 9%–11% | 第4档 ×2.20 | ¥659（只执行一次） |
| ... | 每跨一个完整档位乘 ×1.3 | |

**纳斯达克**（021000, 016452, 016453, 019172, 018043）：入场 5%，每 3% 一档，乘数 ×1.5

| 回撤范围 | 档位 | 买入金额（¥6,000 × 3%） |
|----------|------|--------------------------|
| < 5% | — | 不操作 |
| 5%–8% | 第1档 ×1.00 | ¥180（只执行一次） |
| 8%–11% | 第2档 ×1.50 | ¥270（只执行一次） |
| 11%–14% | 第3档 ×2.25 | ¥405（只执行一次） |
| 14%–17% | 第4档 ×3.38 | ¥608（只执行一次） |
| ... | 每跨一个完整档位乘 ×1.5 | |

回撤 = (前期高点 − 当前净值) / 前期高点 × 100%

### 卖出规则

| 策略 | 公式 | 适用 |
|------|------|------|
| **趋势型** | 卖出点 = 高点 + (高点 − 低点) / 2 | 纳斯达克（高波动） |
| **均值回归型** | 卖出点 = 前期高点 | 低波红利（低波动） |
| **长期持有** | 不生成卖出信号 | 债券/黄金 |

## 命令参考

### add — 添加基金

```bash
python fund_tracker.py add <基金代码> [选项]
```

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `-c, --capital` | 100,000 | 总资金（元） |
| `-r, --base-ratio` | 0.03 | 基础买入比例 |
| `-s, --tier-step` | 5 | 每档回撤幅度（%） |
| `-m, --multiplier` | 1.2 | 档位乘数 |
| `-e, --entry` | 10 | 入场回撤阈值（%） |

### check — 查看状态

```bash
# 查看全部基金
python fund_tracker.py check

# 查看指定基金
python fund_tracker.py check 270042

# 执行买入信号（记录到持仓）
python fund_tracker.py check --execute
```

### config — 修改参数

```bash
python fund_tracker.py config 270042 -c 200000 -r 0.05
```

### backtest — 历史回测

```bash
# 回测近一年
python fund_tracker.py backtest 270042 -d 365

# 回测近三年
python fund_tracker.py backtest 270042 -d 1095
```

### remove — 移除基金

```bash
python fund_tracker.py remove 270042
```
